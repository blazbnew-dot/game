PIXEL WRESTLER ARENA
Made by ChatGPT

使い方:
1. pixel_wrestler_arena.html をブラウザで開いてください。
2. PCはキーボード、スマホ/タブレットは画面下のボタンで操作できます。
3. ドローンを10体倒すと勝利です。

PC操作:
←→ / A,D : 移動
↓ / S     : しゃがみ
SPACE     : ジャンプ
J         : 弱パンチ
K         : 強パンチ
U         : 弱キック
I         : 強キック
L         : ガード
O         : 必殺投げ
T         : 挑発

このHTMLはスプライト画像を内部に埋め込んだ単体ファイルです。
インターネット接続なしでも動作します。
